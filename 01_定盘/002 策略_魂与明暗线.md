# 002 策略 · 魂与明暗线

## 魂（明着说）

**把「AI 好神」，变成「我也能」。**

## 暗线（不点破，靠案例证明）

**「原来，我也能。」**

> D3·下 才点破 → **「你才是发号施令的人。」**

## 明线（三天三段）

|天|台阶|学员那句话|
|---|---|---|
|D1|**敢**|原来，我也能**指挥**它|
|D2|**能**|原来，我也能**做出**一个东西|
|D3|**信**|原来它**凭什么**、我该怎么**一直用**|

## 悬念链（一环扣一环）

D1上「怎么做成跟我一样？」 → D1下「怎么把做法变成可复用的？」 → D2上「东西做出来了，行不行？」 → D2下「专业版凭什么？」 → D3上「它到底凭什么？」 → D3下「那我呢？」

## 三个"不"（防跑偏）

- 不讲技术原理 → 讲"它凭什么"
- 不追求人人会做 → 追求人人"敢想"
- 不重复案例 → 一个案例只讲一次，其余回指
