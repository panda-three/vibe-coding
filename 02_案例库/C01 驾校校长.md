# C01｜一个"两个指头打字"的校长，自己做出了系统

**一句话**：一个没编过程、两个指头打字的山西驾校校长，几个月，做出上百人天天用的系统。

- **Before**：200+ 团队；vibe coding／agent 一个词听不懂；观望、焦虑。第一次试飞书"龙虾"搭表，上午做下午忘。
- **拐点**：被同学当面泼冷水"你大概率做不出来" → "不行就不行呗，试试也没啥。"
- **过程**：
    1. 死磕鸡零狗碎（搞 IP／账号／网络，干到凌晨三四点）
    2. 装上 ClaudeCode——"从站旁边说的角色，变成帮你干的角色"
    3. 双三角落地（做 AI 客服）
    4. 在失败里找拐点：系统没人用还造假 → 醒悟"我把系统当大钉钉了" → 改"传截图、AI 帮分析"+激励 → 几百人喂话术，练出 AI 销售教练
- **After**：一个人做出系统，上百学生代理天天用。"我们好像是山西唯一有小程序的学生组织。"
- **金句**：**"你让我现在想，我都不知道自己当时是不是疯了。"**
