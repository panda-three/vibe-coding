# 优秀教案/宣传稿库｜细节故事线 v1

## 一句话

把优秀家长会发言、学校公众号稿拆成**五件套（标题/开头/结构/金句/禁忌）**喂给 AI——**初版谁都能写；喂了"你的好稿子"之后，明显像你。加数据，比换提示词管用。**

## 成品锚点：两次生成对比（🟡 课堂演示样例）

### 初版（只喂一句话）
- 输入：「帮我写个家长会发言稿」
- 结果：平均风、百度文库味、「感谢各位家长在百忙之中……」——**谁都能写**。
- 认知：AI 只有网上的平均答案。

### 升级（喂三类数据）
- 结果：明显像"**你的风格**"。

## 三类数据（本案例核心，先讲清）

| 类型 | 是什么 | 现场怎么喂 |
|---|---|---|
| **① 标准** | 什么叫"好" | 列 3 条：不告状 / 有具体例子 / 结尾给合作动作 |
| **② 范例** | 优秀样本 | 把 3 篇优秀发言拆成五件套 |
| **③ 反馈** | 修改记录/失败记录 | 写上"上次哪段家长不爱听"（禁忌：命令式口吻、只报忧不报喜） |

### 成品锚点：家长会发言稿·五件套（🟡 演示样例）

- **标题**：不叫"家长会发言稿"，叫《**孩子最近在学校的三件小事**》（具体、有温度）。
- **开头**：不"感谢百忙之中"，而是"今天不讲大道理，先跟您说三件这周我观察到的小事"。
- **结构**：
  1. 先讲一个孩子的进步（具体）；
  2. 再讲一个我们一起要注意的问题；
  3. 最后给一个回家就能做的小动作。
- **金句**：「孩子的问题，往往是家庭和学校没对上频道。」
- **禁忌**：
  - 不点名批评（告状）；
  - 不说"你们家长要好好管"（命令式）；
  - 不只报忧不报喜；
  - 不空话套话。

## 操作步骤（B 型流程）

1. 定标准：写下 3 条"好发言稿"的标准；
2. 拆范例：把 3 篇优秀稿拆成五件套；
3. 记反馈：把上次家长不爱听的点写成禁忌；
4. 让 AI 写 → 对比初版 → 明显像你。

## 处理四步（数据怎么加工）

- **脱敏**：去掉学生姓名、隐私；
- **结构化**：拆成五件套；
- **标签化**：打标签（进步/问题/动作/禁忌）；
- **版本化**：保留每次修改（见 C 题库过程数据）。

## 核心认知点

1. **三类数据**：标准 / 范例 / 反馈。
2. **加数据比换提示词管用**：从"平均答案"走向"你的答案"。
3. **数据是私有资产**：喂标准/样例/反馈，不喂隐私。
4. **数据不是一次做完的，是边干边攒的复利**（过程数据最值钱，与 C 题库呼应）。

## 惊讶钩子

- **反差**：同一道指令，初版像百度抄的，喂了三篇你的稿子后，文风、结构、禁忌全变成你。
- **算账**："不是 AI 变聪明了，是你把自己的好东西喂给了它。"
- **提问**："你手机里、电脑里，有多少'好稿子'还没被拆成 AI 能用的数据？"
