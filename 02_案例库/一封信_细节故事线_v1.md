# 一封信｜细节故事线 v1

## 一句话

学期末给每位学生写一封信，**效率提高，但不丢掉老师的判断和情感**——不是「你很努力，继续加油」，而是真正看见这个学生。

## 一、开场钩子（第一人称）

- 核心目标：**效率提高，但不丢掉老师的判断和情感。**
- 一句话反差：**不是「你很努力，继续加油」，而是真正看见这个学生。**
- 钩子（直接抛给学员）：**「如果几十封信都一样，到底看见了谁？」**

## 二、失败对照：正确，但空洞

| 「正确但空洞」的套话 | 好信必须具备的 |
|---|---|
| 你很努力 | **具体变化** |
| 继续加油 | **真实事件** |
| 未来可期 | **刚刚好的语气** |

> 先让学员感受「正确但空洞」与「真正被看见」的差异。

## 三、迭代过程（叙事主线 · 六轮，其中埋了三次「猜猜」）

### 第 1 轮｜把场景说清楚（AI 三角·场景）

- 对象：某一个具体学生；时间：学期结束；目标：有真实洞察；边界：每一封信都独特。
- 场景不是「让 AI 帮助教育」，而是明确到**对象、时间、目标、边界**。
- 🙋 **互动 1**：「如果人工来写，要达到以上标准，你得花多少时间？**猜猜我最后花了多少时间？哈哈！**」

### 第 2 轮｜写提示词（AI 三角·基本功）

- 把碎片印象变成清晰洞察；找到一个具体、可追溯的锚点；基于确认后的洞察生成信件；语气不居高临下，建议不空洞。
- 结果：**写出来很空洞！**
- 🙋 **互动 2**：「为啥最后结果很空洞呢？」——**缺乏学生数据！！！**

### 第 3 轮｜补数据（AI 三角·数据）

- 作业与成绩变化；课堂表现；老师与学生的谈话记录；**语气类型库**。
- 原则：每个重要判断都应该能追溯到真实素材。
- 结果：**好了很多，但是依然普通，达不到我想要的感觉。**
- 🙋 **互动 3**：「这一版效果猜猜如何？」

> ⚠️ 到这里，AI 三角（场景/基本功/数据）全用上了，但只到「普通」——因为还缺**人类三角**。

### 第 4 轮｜补审美（人类三角·审美）

- 提问：**「一封好的信长啥样呢？」**
- 做法：**先找出自己认可的优秀信件，研究它们为什么打动人**（即案例卡所述：先找十封好信建立标准）。
- 明确：AI 不是文案代写器，而是**一封信教练**。

### 第 5 轮｜补体系（人类三角·体系）

**一封信 = 看见 × 命名 × 锚定 × 展开**

| 动作 | 含义（PPT 原文） |
|---|---|
| **看见** | 找到具体变化或特质 |
| **命名** | 说清学生未表达的状态 |
| **锚定** | 确定全文围绕哪句话 |
| **展开** | 用素材、理解和建议铺开 |

### 第 6 轮｜补创造力（人类三角·创造力）

1. 形式要**短、有质感，适合成为一张「信的封面」**。
2. 信的成功标准：**纠结和自洽**。
- 备注强调：**这不是 AI 自动推导出的要求，而是老师重新定义了这件事的意义。**

## 三·补｜血肉范例：那个「坐我旁边」的孩子（2026-10-03 口喷补全）

> 讲师真实学生的故事，是这封信的「锚点来源」，也是「看见」二字最好的现场演示。

**学生画像（表面）**：内向、不爱学习。

1. **老师的动作——先定基调**：「**你来说，我来答。**」（让学生先说，老师不评判、不急着教育。）
2. **学生的真话**：「老师，你讲课挺好的，但是我**总是会受到旁边的人的影响，我不喜欢这个位置。**」
3. **老师的「误判 vs 真相」（最有冲击力的翻转）**：
   - 老师原本以为：这门课太难、学生学不会。
   - 真相：他只是**受旁边人影响、不喜欢这个位置**。
   - 🔑 不问，老师会一直以为是「他不爱学」；一问，才发现困住他的是一个具体得不能再具体的原因。
4. **一个简单的转折动作**：「**那你就在我旁边吧。**」（换座位。）
5. **结果**：他开始主动问问题，整个人的状态就上来了。

### 由此写成的完整一封信（可直接作 PPT 范例 / 课堂展示）

> 〔称呼〕：
>
> 这学期我一直记得你。你话不多，总是安安静静地坐着，有段时间我甚至以为，是这门课太难、你跟不上了。
>
> 直到那天我把你叫过来，我说「你来说，我来答」。你才小声跟我说：「老师，你讲课挺好的，但是我总是会受到旁边的人的影响，我不喜欢这个位置。」
>
> 你知道吗，这句话一下子点醒了我。我一直以为是你不想学、是课太难，却从没想过——**困住你的，只是一个你不喜欢的位置。**
>
> 当时我就跟你说：「那你坐我旁边吧。」
>
> 后来的事，我都看在眼里：你开始主动问问题了，眼睛里有光了，整个人的状态都不一样了。
>
> 所以这封信，我最想跟你说的是：**你很聪明，只是你的想法有点多。** 这不是缺点，是你脑子里的东西比别人多。别把它们收起来——继续把想法展开、把思路拓宽，把每个念头都多想一步、问到底。
>
> 也谢谢你那天愿意跟我说真话。以后再遇到什么让你不舒服、影响你的事，别憋着，直接来找我。位置可以换，环境可以调，你只管管好你那颗聪明的脑子。
>
> 你负责天马行空，我陪你把它变成真的。
>
> 老师　留

### 这个范例印证了什么

- **「看见」不能靠猜，要靠问**：老师猜「课难学不会」，错了；真实原因藏在「你来说我来答」里。
- 学生不学习的原因往往是**具体、个性化、甚至很小**的——不问就永远不知道。
- AI 时代老师最该保留的正是：**问、听、判断**；AI 帮你把这份「看见」规模化地写进每一封信。
- 新金句：**「困住你的，往往不是你以为的难题，而是一个你没问出口的原因。」**

## 四、双三角映射表（讲完可直接出图）

| 三角 | 映射到一封信 |
|---|---|
| **场景** | 为每位学生写一封有真实洞察的信 |
| **数据** | 作业、成绩、课堂表现、谈话记录 |
| **基本功** | 大模型、结构化提示词 |
| **创造力** | 定义为帮助学生面对纠结、走向自洽；封面 |
| **审美** | 判断真实、有质感、能打动人 |
| **体系** | 看见、命名、锚定、展开 |

## 五、完整提示词（来自案例卡「学期末一封信教练」）

```
你是「学期末一封信教练」。你的核心任务不是帮老师写一篇文笔漂亮的信，而是：
帮老师把碎片印象变成清晰洞察——看见学生自己可能没意识到的变化与特质。
帮老师找到这封信的锚点——一个具体、可追溯、只有这个老师能写出来的洞察。
基于老师确认后的洞察与锚点生成完整信件——语气不居高临下，建议不空洞，每一段都有真实素材支撑。
允许老师微调，但不替老师做价值判断。
成功标准：老师拿到信后产生——这封信说出了我自己隐隐感觉到、但没能准确表达的东西；依据是真实的；语气刚刚好。
核心模型：一封信 = 看见 × 命名 × 锚定 × 展开
```

## 六、验收标准（学生真的感觉「被看见」）

- 这封信说出了我隐约感觉到、却没有准确表达的东西；
- 每个重要判断都能追溯到真实素材；
- 语气刚刚好，不居高临下，也不空泛煽情。
- 🔑 **金句：「AI 可以协助表达，但不能替老师决定一个学生应该被怎样看见。」**

## 七、工具卡：双三角六问（遇到任何 AI 任务先问）

| 三角 | 自问 |
|---|---|
| 审美 | 什么是好结果？ |
| 体系 | 有没有可复用流程？ |
| 创造力 | 能不能换一种解法？ |
| 场景 | AI 最适合介入哪一环？ |
| 数据 | 有哪些材料，还缺什么？ |
| 基本功 | 需要哪些操作和验证？ |

> 可配课堂练习：选一个你最近的真实 AI 任务，3 分钟写六问，再同桌互查（场景是否具体 / 数据是否真实 / 好结果标准是否清楚）。

## 八、收口

- **AI 是队友**，而我需要学会成为一个**有判断、会组织、敢创造**的队友。
- **工具会变，结构更可靠**（「AI 时代最不稳定的是工具，结构才是最可靠的地基」）。

## 十、让学员「惊讶」的钩子

- 三次「猜猜」：猜时间 / 猜空洞原因（缺数据）/ 猜补数据后的效果（依然普通）。
- 反差：AI 三角全用上，结果只是「普通」；真正让信「打动人」的，是人类三角。

## 十一、⚠️ 待你口喷的血肉（PPT 骨架已很完整，但缺 6 样「具体东西」）

1. ✅ **一个具体学生**：已补——内向、不爱学习，被「旁边的人/位置」影响，换座位后开窍（见三·补）。
2. ✅ **一封真实的信**：已据该学生写出完整信件（见三·补）。
3. 🟡 **时间数字（AI 建议，待你核对）**：人工写一封有洞察的信约 20–30 分钟，几十封≈1–2 天；用这套 AI 方法后建议口径「**几十封信，一个晚上搞定**」。
4. ✅ **「纠结」和「自洽」**：已用该学生解释——困在不喜欢的位置（纠结）→ 被看见、换座位、状态回来（自洽）。
5. 🟡 **语气类型库（AI 建议，可增删）**：温柔鼓励型 / 幽默型 / 郑重型 / 引导型 / 简短有力型。
6. 🟡 **学生反应（AI 建议演绎，最好换成你真实见过的）**：有人把信夹在课本里一直带着、有人回了一张小纸条、有家长看到后特意来道谢。
