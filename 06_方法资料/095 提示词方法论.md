# 095 提示词方法论（一堂AI提问第一课·知识包）

> **来源**：whyai 课程版AI《一堂AI提问第一课》知识包（conversation 03034da5-a8b5-411d-8be5-6f531b2eb101，2026-09-30 抓取）
> **适用对象**：成年人、零基础、手机豆包App用户。
> **核心一句话**：**AI不是读心术。提示词就是给AI派活。你说得越像给新同事交代工作，它干得越准。**

---

## 一、底层认知：把AI当"超级实习生"

不要一上来只给一个词："写文案""写请假条""做计划"。
AI不知道：给谁看？什么场景？多长？什么语气？要什么格式？
**提示词的本质不是咒语，而是派活说明书。**

## 二、四条核心原则

1. **目标先于文采**：先告诉AI要什么结果，不是只给主题。差："帮我写苹果"。好："帮我写3条卖苹果的朋友圈文案，目的是让邻居接龙购买。"
2. **背景先于技巧**：对象、场景、已有信息说清楚。差："写个通知"。好："写一个小区家长群通知，明天上午9点停水，预计下午3点恢复。"
3. **具体先于笼统**：字数、语气、重点、禁忌都说。差："写得好一点"。好："80字以内，口语化，像邻居推荐，不要像广告，结尾引导评论'要几斤'。"
4. **迭代先于一次到位**：第一版不满意很正常。不要重新开一大段，直接追问："太正式了，换成微信聊天口气。""太长，缩到100字。""再给3个版本：正式、亲切、幽默。"

## 三、五步提问法（零基础最好记）

| 步骤    | 做什么            | 例子                             |
| ----- | -------------- | ------------------------------ |
| 1 定角色 | 让AI扮演谁         | 你是一名社区团购水果店老板                  |
| 2 定任务 | 到底让它做什么        | 请帮我写3条朋友圈文案                    |
| 3 补背景 | 给谁看、什么场景、已知信息  | 卖给小区邻居，5斤29.9元，今晚8点截单，明天到货     |
| 4 提要求 | 语气、字数、重点、禁忌    | 口语化，像邻居推荐，每条80字以内，突出便宜新鲜，不要像广告 |
| 5 定格式 | 要几条、分点、表格、微信消息 | 编号1—3，每条独立；再给1条幽默备用版           |
|       |                |                                |

**第6步（兜底）**：让AI先问你——"如果信息不够，请先问我3个问题，再开始写。"

## 四、万能公式

```
角色 + 任务 + 背景 + 要求 + 格式 + 示例 + 追问
```

可直接套用：
> 请扮演【角色】。
> 帮我完成【任务】。
> 背景是：【对象、场景、已知信息】。
> 要求：【语气、字数、重点、禁忌】。
> 输出格式：【几条、表格、微信消息、清单等】。
> 参考示例：【如果有就放一个】。
> 如果信息不够，请先问我3个问题，不要直接写。

零基础简版：
> 你是【谁】。
> 我要【做什么】。
> 给【谁】看，在【什么场景】用。
> 要求【语气/字数/重点】。
> 输出成【什么格式】。
> 信息不够先问我。

**追问公式**：针对【哪里不满意】，改成【什么方向】，保持【什么不变】，输出【什么格式】。
例："针对语气，改成更口语，保持价格和截单时间不变，输出3条。"

## 五、案例包（零基础完整案例）

### 案例1：卖苹果朋友圈文案

**不会写的问法**："帮我写个卖苹果的文案。"
AI可能输出："新鲜苹果上市，脆甜多汁，营养丰富，欢迎选购！"——太泛，像万能广告。

**写好的问法**：
> 你是一名社区团购水果店老板，擅长写朋友圈。
> 请帮我写3条卖烟台红富士苹果的朋友圈文案。
> 背景：卖给我所在小区的邻居，5斤29.9元，今晚8点截单，明天到货，脆甜多汁，先到先得。
> 要求：像邻居推荐，不像广告；口语化，每条80字以内；突出便宜、新鲜、今晚截单；带1—2个emoji；结尾引导评论"要几斤"。
> 输出格式：编号1—3，每条独立。先写3条，再给1条更幽默的备用版。
> 如果信息不够，先问我3个问题。

**对比总结**：

| 不会写 | 写好 |
|---|---|
| 只给主题：卖苹果 | 给角色：社区团购水果店老板 |
| 没对象：不知道给谁看 | 给对象：小区邻居 |
| 没信息：价格、时间都没有 | 给背景：5斤29.9、今晚截单、明天到货 |
| 没要求：不知道什么语气 | 给要求：口语化、像邻居、80字内 |
| 没格式：不知道几条 | 给格式：3条+1条备用 |

### 案例2：给领导的请假微信

**不会写的问法**："帮我写请假条。"——像公文，没说时间原因工作安排。

**写好的问法**：
> 你是一名职场沟通顾问。
> 请帮我写一条给部门王经理的微信请假消息。
> 背景：我明天下午要带孩子打疫苗，需要请半天假；手头工作已交接给小李；我和王经理平时沟通正常，公司请假需提前说。
> 要求：礼貌、简洁、不卑微；说清请假时间、原因、工作已交接；100字以内；不要用"望批准""特此申请"；结尾用"您看可以吗"。
> 输出格式：一条微信消息，再给一个更简短的版本。

## 六、手机豆包实操要点

### 万能实操模板（第一次不会写就直接复制）
> 请扮演【角色】。
> 我要【任务】。
> 背景：【给谁看/什么场景/已知信息】。
> 要求：【语气、字数、重点、不要什么】。
> 输出格式：【几条、表格、微信消息、清单】。
> 如果信息不够，请先问我3个问题，不要直接写。

### 追问口令（零基础直接发）
- "太正式了，换成微信聊天口气。"
- "太长，缩到100字以内。"
- "再给我3个版本：正式、亲切、幽默。"
- "分点写，每点一句话。"
- "用初中生能懂的话解释。"
- "把重点加粗，结尾给我行动建议。"
- "检查有没有敏感信息，帮我脱敏。"
- 医疗/法律/投资问题，请提醒核实官方信息。

### 常见场景提示词（可直接套）
- **写微信消息**：你是一名职场沟通顾问，帮我写一条给___的微信，背景是___，要求礼貌简洁，100字以内。
- **写朋友圈/群文案**：你是一名擅长朋友圈文案的店主，帮我写3条，背景是___，要求像邻居说话，带emoji，结尾引导评论。
- **生活办事**：你是一名生活助手，请用大白话告诉我怎么操作，分步骤，每步一句话，适合老人看。
- **拍照/上传提问**：拍商品图写团购文案；拍药盒解释用法并标注意事项；拍说明书总结3个重点。
- 注意：医疗、法律、投资、政策类信息，必须再找官方渠道核实。

### 实操流程（7步）
1. 打开豆包App，新建对话
2. 发第一条：角色+任务+背景+要求+格式
3. 加一句："信息不够先问我3个问题"
4. 豆包回答后不要急着复制，先追问一两次
5. 复制结果，改人名、时间、数字、地点
6. 检查事实和隐私，再发出去
7. 好用的提示词存到微信收藏或备忘录，下次直接改

### 零基础避坑
- 不要只说"帮我写个东西"，信息太少
- 不要一次让豆包做十件事，一次一个目标最稳
- 不要发身份证、银行卡、密码、公司机密、孩子学校等敏感信息
- 不要直接复制就发，先人工改一遍
- 手机打字慢就用语音，但语音也要说清"给谁、做什么、什么要求、什么格式"

## 一页纸速查

**万能公式**：角色 + 任务 + 背景 + 要求 + 格式 + 示例 + 追问
**五步法**：定角色 → 定任务 → 补背景 → 提要求 → 定格式
**三句追问**：太正式了，换口语。／太长了，缩到100字。／再给我3个版本。
**记住一句话**：提示词不是咒语，是派活说明书。你说得越清楚，AI干得越漂亮。
