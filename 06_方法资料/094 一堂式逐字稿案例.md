# 094 一堂式逐字稿案例·最佳实践

> 来源：课程版AI 对话抓取（2026-09-30，conversation 8035bdbe-…）
> 用途：[[240 D1上_逐字稿_v3]] 的写法底座——一堂式逐字稿长什么样、成人课堂互动怎么写。
> 一句话：**成人课不追求整齐，追求跑通；不强制互动，尊重、自主、给结果。**

---

## 一、三个真实切片（样稿）

### 切片1｜开场段（低压力跟做）

**讲师：** 就用你手上这台手机。打开豆包。不用电脑，不用装环境。  
【互动：低压力跟做】

**讲师：** 现在做一件事：打开豆包，让它亮着。**不用举起来，不用发群里，不用扣1。你只要让它亮着。**  
（停3秒，扫视）

**讲师：** 因为接下来每一个演示，你都要跟着点一次。  
【切PPT】三天后带走什么。

**讲师：** 三天后，你会带走三样东西：一个能跑通的小工具，一套跟AI说话的提示词框架，一个卡住能自己修的操作习惯。  
（停2秒）

**讲师：** 我们开始。

### 切片2｜演示段（慢、不用抄、先跑通）

**讲师：** 接下来这段，我会很慢。你不需要抄。你只需要做两件事：看我输入什么；把这句话复制到豆包。  
（停1秒）

**讲师：** 先别急着问"为什么"。成人学习最快的方式不是听懂每个原理，是先跑通一次。  
【动作】打开豆包，输入框光标亮起。

**讲师：** 我在输入框打这句话——（大屏逐字出现）
> 你现在是一个产品经理。请帮我做一个手机端可用的极简待办清单，只要一个HTML文件，包含添加、删除、完成三个功能。界面大按钮，适合单手操作。不要解释，直接给代码。

**讲师：** 注意，这句话里有三块：角色、任务、限制。你不用背，等会儿给你一张填空表。  
【动作】点击发送。（停1秒）

**讲师：** 现在它生成。这个等待时间，正好讲一个关键点：AI不是魔法，它需要你把验收标准说清楚。  
（停1秒）

**讲师：** 比如"大按钮、单手操作"，就是验收标准。你不说，它给你一个能跑但难用的东西。  
【结果出现】

**讲师：** 出来了。第一次验收：复制到手机浏览器，能不能打开？能，就打"能"；不能，就打"不能"。**注意，不是打1，是打你真实结果。**  
（停3秒）

**讲师：** 我看到有人打"能"，也有人打"不能"。打"不能"不是失败，你刚刚定位了一个真实问题。下一步就修这个。  
【切PPT】三步验收：能打开、能点击、能保存。

**讲师：** 你发现没有？我们不是在听AI课，是在修一个真实的小工具。**成人课不追求整齐，追求跑通。**

### 切片3｜收口段（心里回答三问）

**讲师：** 今天不总结知识点。我只问三个问题。**你不用回答我，在心里回答。**  
（停2秒）

**讲师：** 第一，今天跑通的那一步，明天能不能用在工作里？第二，如果卡住，你知道翻哪页截图吗？第三，你愿不愿意把刚才那句话，换成你自己的业务场景再试一次？  
（停3秒）

**讲师：** 如果都是能，你今天赚了。有不能，正常。成人学习不是一次听懂，是回去用一次。  
【切PPT】今晚任务。

**讲师：** 今晚任务只有一个，**不打卡，不接龙**。用豆包做你工作里最烦的一件小事，做完截图放自己相册。明天我们拆真实案例。  
（停1秒）

**讲师：** 记住这句话：**你不是在学AI，你是在把AI变成你的实习生。**  
（停2秒，收）

## 二、一堂式逐字稿的写法特征

### 有什么

| 元素 | 写法 | 例子 |
|---|---|---|
| 时间轴 | 精确到分钟/模块 | 00:00-03:20、12:10-18:40 |
| 大屏画面 | 明确写切页内容 | 【切PPT】三天后带走什么 |
| 动作标注 | 讲师身体、手机、投屏、点击 | 【动作】举起手机，手机画面投到大屏 |
| 停顿 | 精确到秒 | （停2秒）（停3秒） |
| 互动 | 低压力、可选、真实结果 | "能就打能，不能就打不能" |
| 金句 | 单独一行，短，可记 | "你不是在学AI，你是在把AI变成你的实习生。" |
| 转场 | 每段有下一步 | "接下来这段，我会很慢。" |
| 异常分支 | 卡住怎么办 | "打'不能'不是失败，下一步就修这个。" |
| 口语短句 | 像说话，不像念稿 | "我们开始。" |
| 成人语气 | 尊重、不命令、不幼稚 | "你不用回答我，在心里回答。" |

### 没什么（一堂式逐字稿不写这些）

- 不写"同学们，大家好，今天我们来学习……"
- 不写大段定义、历史、原理铺陈
- 不写没有动作、没有停顿、没有切页的纯口播
- **不写强制互动：全班打1、举手点名、齐读**
- **不写幼稚奖励：小红花、棒棒糖、积分、请吃饭、发红包**
- 不写空问题："听懂了吗？""明白了吗？"
- 不写过度煽情、喊口号、破冰游戏
- 不写让成人尴尬的公开比较、公开排名、公开批评

### 标点与语气

- 句号多、短句多；问号用于钩子和自检，不用于逼问；破折号用于转折；感叹号少、情绪克制；冒号用于指令
- 方括号/圆括号用于舞台提示：【动作】、（停2秒）

## 三、成人课堂互动清单（小孩课堂 → 成人课堂）

| 小孩课堂做法 | 成人课堂换成 | 逐字稿句式 |
|---|---|---|
| 全班打1 | 打真实结果/关键词，或自检 | "能就打能，不能就打不能；不想打就自己看屏幕。" |
| 点名举手机 | 让手机亮着/打开豆包，不检查 | "打开豆包，让它亮着，不用举。" |
| 齐声回答 | 心里回答/可选评论区 | "你不用回答我，你在心里过一遍。" |
| 举手点名 | 匿名投票/自测清单 | "对号入座，符合打钩。" |
| 小红花/积分 | 截图带走/模板带走/跑通结果 | "这一步不用记，截图即可。" |
| 请吃饭/发红包 | 给可复用模板/案例拆解 | "课后给你提示词表。" |
| 强制打卡接龙 | 真实任务，不打卡 | "今晚用一次，做完截图放相册。" |
| 321倒计时催 | 给下一步，停3秒等跟上 | "我停3秒，你打开豆包。" |
| 公开排名/批评 | 匿名/私密自检 | "卡住正常，下一步修。" |
| 破冰游戏/小组讨论 | 单人跟做/同桌互看可选 | "你可以自己试，也可以看旁边人。" |

**成人互动四原则**：①**自主**——可选、不强制、不点名；②**面子**——不公开暴露"不会"、不幼稚；③**结果**——每个互动都为跑通、带走、能用；④**时间**——不浪费，直接跟做，一句话说清下一步。

**单人单机大屏最适用的互动**：打开豆包让它亮着／跟着输入一句话／能·不能打真实结果／截图放相册不打卡／心里自检三问／评论区可选反馈不强制接龙。

## 四、对本营的启示（应用到 v3 及之后）

1. **所有"打1/举手/举手机/齐读/请吃饭"类话术从逐字稿删除**，换成"打真实结果/心里回答/手机亮着不用举"；
2. 演示段参考切片2节奏：慢、不用抄、先跑通、等结果时讲关键点；
3. 收口参考切片3：三问心里答＋真实任务不打卡；
4. 金句单独一行（参考"你不是在学AI，你是在把AI变成你的实习生"——本营对应"你没写一行代码/先跑起来再改/你才是发号施令的人"）；
5. 标点语气：短句、少感叹号、冒号给指令、（停N秒）精确停顿。
