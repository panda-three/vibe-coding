# 050 案例打磨方法卡

## 模板

**背景(Before) → 过程(Method) → 结果(After)**

## 验收三要点（不过就是废卡）

1. 能够带入（场景＋细节）
2. 体现方法（讲能力构建，**不能纯讲故事**）
3. 案例完整（**有 Before 和 After，不能前后都牛逼**）

## 四步

1. 收集（磨课手段：访谈／作业挖掘／调研）
2. 拆解（像素级：只抓 Before / After / Method）
3. 打磨（张力＝Gap 要大；十指讲香）
4. 沉淀（卡片化 → 入库）

## 两套卡，别混

- **库卡**（建库/检索）：一句话/起点/步骤/工具/数据/结果/展示/亮点/哇点
- **讲述卡**（上台）：加张力/金句/十指

> 先建库 → 再取货 → 才讲香
