# 099 D1上阶段复盘（方法论对照）

> **复盘范围**：当前 session 中 D1上（D1上1＋D1上2）备课全流程——双三角盲区复盘 → 方法论抓取（090/091/092/093/094/095）→ 逐字稿 v1→v6 → D1上2 v1→v2 → 大纲 v1→v5 → 命名拆分与版本化。

## 四、方法论给本阶段的三个总判断

1. **最成功的一步**：规格决策（底稿制）＋成人化互动——这两件事决定了所有逐字稿的"对不对"，方向从 v2 起没有翻过车。
2. **最该补的一环**：判定标准——锚点可观察性、演示"炸在哪一句"、学员水位样本，三件都是 013 指出的"判定标准不够"，不是内容不够。
3. **最大的隐性风险**：时长——8 名词链＋13 分钟自由做，两处都可能超时；超时即崩盘（认知课超时=后半段全部压缩）。
