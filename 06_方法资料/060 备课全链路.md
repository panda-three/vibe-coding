# 060 备课全链路

## 流水线

魂 → 框架 → 案例打磨 → 干货点清单 → 大纲 → 逐字稿 → 讲香 → PPT → 交付

## 比喻

| 环节    | 比喻     | 解决       |
| ----- | ------ | -------- |
| 案例卡   | 🥩 食材  | 有没有具体的东西 |
| 干货点清单 | 🧊 冰箱  | 够不够全     |
| 大纲    | 📋 菜单  | 顺序对不对    |
| 逐字稿   | 🍳 烹饪  | 讲不讲得出    |
| PPT   | 🍽️ 摆盘 | 看不看得清    |

## 病根

从"菜单"跳到"摆盘"——冰箱里没食材，摆出来就是空盘。

## 传动轴

- 案例卡 → 一颗颗有肉的子弹
- 干货点清单 → 弹药＋分类
- 大纲 → 结构＋顺序＋时长
- 逐字稿 → 人话＋【PPT】锚点
- **PPT 是逐字稿的配图，不是独立创作**

## 大纲的两层

- **大纲稿**＝要点 list（粗，指导）
- **半逐字稿**＝上台用（细）

> 大纲写"动词"，不写"台词"。

## 大纲必带「审核速览」（验收标准，2026-10-03 沉淀）

大纲交付时，**必须配一张一页纸的审核速览**，让审稿人不用逐页读几十页逐字稿。三件套：

1. **全天导航表**：时间｜块｜讲什么｜案例成品｜血肉状态。
2. **血肉状态标记**（一眼看出哪里空）：
   - 🟢 有知识库原话 / 成品；
   - 🟡 可现场演示、无需提前准备；
   - 🔴 缺真实素材，会飘（点名需要讲师补什么）。
3. **判断题**：把需要拍板的争议点浓缩成 ≤5 条，每条可直接"对/丢弃/改"。

> 用法：审稿先看速览 → 答判断题 → 只补 🔴；不必逐字读逐字稿。
