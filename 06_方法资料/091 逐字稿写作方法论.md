# 091 逐字稿写作方法论（课程版AI）

> 来源：课程版AI 对话抓取（2026-09-30，两次：conversation 方法论＋细节）
> 用途：把 [[060 备课全链路]] 的「大纲→逐字稿」这步落地的操作手册。配套小样见 [[240 D1上_逐字稿]]。
> 一句话总纲：**结构单位负责推进，口语化负责听懂，演示词负责看见，金句负责记住，互动负责确认。**

---

## 1. 块结构（一个 10-15 分钟块的七个件）

| 件 | 干什么 | 一句话示例 |
|---|---|---|
| 钩子 | 开场制造缺口，不是"接下来我们…" | "同样一句话，两个人问，结果差十倍。" |
| 锚 | 先给结论，≤20字，上大屏，全块出现3次 | "不是它不懂你，是你没说清。" |
| 拆解 | ≤3点，每点＝名字＋解释＋例子 | "第一，对象。给谁看。第二，目标。要什么。第三，禁忌。不要什么。" |
| 演示 | 预告三件套→演示中五条解说→收口四步 | 见第4节 |
| 跟做 | 指令句＋时间盒＋兜底话术，手机操作≤3步 | "打开豆包，把刚才那句话改成你的主题，60秒。" |
| 回收＋锚点 | 最后一句必须是"你现在应该已经拥有/看到/说得出 ××" | "低头看手机——有回复的，抬头看我。" |
| 桥 | 制造缺口，连到下一块 | "但它写太长了怎么办？下一块解决。" |

**写法铁律：倒着写——先写锚点，再写台词。**

## 2. 口语化手法（书面→口语）

| 手法 | 做法 | 对照 |
|---|---|---|
| 短句 | 一句一口气念完 | "为什么记不住？因为没加工。什么叫加工？就是复述。" |
| 缩句/去术语 | 删"通过、进行、从而、因此" | "多复述几遍，它才进长期记忆。" |
| 换人称 | 学习者→你/我们 | "你先给自己定个目标。" |
| 动词化 | 名词动作→动词 | "把信息分组。" |
| 具体化 | 数字、时间、场景 | "今天学，明天看，三天后再看，比一口气看十遍强。" |
| 对比/反常识 | 先立常见错，再翻过来 | "一口气练十遍？不如分开练。" |
| 语气词/停顿 | 来、注意、啊、好 | "来，注意一下——这里最关键。" |
| 设路标 | 告诉学员到哪了 | "第一，目标。第二，切换。现在说第二。" |
| 降威胁 | 不逼回答，先心里想 | "不用急着说，先在心里想三秒。" |

## 3. 演示词写法（你的红线"每名词必当场演示"就靠这个）

**演示前·预告三件套**
1. 预告任务："接下来我用一句话做两样东西。"
2. 预告验收："看完你要能说出：一句话里到底装了什么。"
3. 预告观察点："重点看：我全程只打字，不写代码。"

**演示中·五条解说**（每一条都说出来）
1. 动作解说："我现在先打字：'一张星空海报'。"（我现在做什么）
2. 原理解说："为什么是这句话？因为细节越多它越懂。"（为什么这么做）
3. 关键点解说："关键在这：只描述你要什么，不写怎么做。"（最重要的一步）
4. 纠偏解说："如果你只说'做个海报'，它就会给你个随便的。"（常见错＋怎么调）
5. 迁移解说："你工作里要个通知配图，也这样一句话。"（连到学员生活）

**演示后·收口四步**
1. 回放步骤："刚才就两步：说一句话，等它出结果。"
2. 强调验收："你能让手机30秒出一张图，就算会。"
3. 点常见坑："别一上来要求完美，那是坑。"
4. 交棒跟做："现在你来，30秒，给自己做一张。"

**双轨制**：左轨说话、右轨动作。逐字稿里必须有【切屏】【停3秒】【看大屏右上角】【拿起手机】这类屏幕坐标口令——学员只有手机＋大屏，没视觉锚定10秒就跟丢。**不要用"这里/这个"，要用坐标**："看右上角那行字。"

## 4. 金句写法（≤12字）

- 炼法：抓核心矛盾（有限vs无限/一次vs多件/先vs后）→ 留动词名词 → 对仗/押韵/数字 → 压到12字内 → 测试：学员能听完就说出来。
- 时机：①钩子后/锚点处（定概念）②拆解中/演示前（回扣）③回收/结尾（收束）④桥接时可说变体。
- 次数：同一句至少3次、最多5次，间隔2-3分钟；每块1句，别喊口号。
- 对照：书面"目标越具体越容易执行" → 金句"越具体，越省事。"

## 5. 互动/提问（成人低风险）

- 形式：手势/举手、选择题打1打2、填空接话、一分钟纸笔、同伴互说、自我检查、场景判断、复述金句。
- 原则：**问题要小、能选、能手势、能复述**。别问"听懂了吗"，要问"能说出第一步吗？"
- 救场阶梯（没人回答）：数三秒心里想→降难度改举手→改填空→同伴互说→自曝示范→点名安全（选A还是B，不用解释）→幽默化解（"沉默说明我问大了，换个小的"）→直接给答＋点头确认。

## 6. 验收锚点（每块必有）

- 公式：【本块锚点·第X分钟】＋主体（学员/大屏）＋可见动作＋可判定结果
  - 例：【本块锚点·第11分钟】全体学员手机里出现一条豆包回复。
- 三硬要求：**可判定**（有/没有）、**可观察**（台下看得出来）、**时间点明确**（写进第几分钟）。
- 埋法三步：块首预告"这一块结束你手机上会多一个东西"→块中推进"还差一步"→块尾点名"低头看手机，有结果的抬头看我"【停3秒】。
- 话术："做到的打1，没做到的别急，我兜底。""这就是我刚才说的那个东西，现在它在你手里了。"

## 7. 时长配比（12分钟块）

| 环节 | 时长 | 占比 |
|---|---|---|
| 钩子 | 0.5–1′ | 8% |
| 锚 | 1′ | 8% |
| 拆解（≤3点） | 3–4′ | 27% |
| 演示 | 3′ | 25% |
| 跟做 | 2′ | 17% |
| 回收＋锚点 | 1.5′ | 12% |
| 桥 | 0.5′ | 4% |

15分钟块：拆解4′/演示4′/跟做3.5′，其余同比例。
**铁律：不要靠拉长"讲"凑时间，要加"练"和"停"。**

四条节奏硬规则：
1. 每 7-8 分钟一次状态切换（讲→看→做→说），否则成人开始摸手机；
2. 连续演示≤4分钟，超过必须插"停、看、问"；
3. 每块实操占比≥15%；
4. 口语按 **200字/分钟** 估算，写完砍20%（现场永远比想象慢）。12分钟块≈1800-2200字。

## 8. 四个坑

1. **讲稿体**：名词化长句→念课文。解法：写完朗读一遍，念不完一口气的拆。
2. **只写讲什么、不写看哪里做什么**：没有【切屏】【停3秒】【拿起手机】。解法：双轨制。
3. **没有验收锚点**：块间断链，"听了很多什么都没留下"。解法：倒着写，先写锚点。
4. **追求逐字完整**：5000字一块，不敢脱稿。解法：只逐字写关键件（钩子/锚/金句/演示解说/验收话术），其余关键词＋箭头；三色标记：黑=必说、蓝=可发挥、灰=备用；每块稿末写"这一块只许记住的一句话：____"。

## 9. 块级自检清单（写完打勾）

- [ ] 有钩子，第一句不是"接下来我们…"
- [ ] 有锚，≤20字，上大屏，出现3次
- [ ] 拆解≤3点，每点有名字＋解释＋例子
- [ ] 演示有"预告三件套＋五条解说＋收口四步"
- [ ] 演示中有屏幕坐标口令，无"这里/这个"
- [ ] 跟做有指令句＋时间盒＋兜底话术，手机操作≤3步
- [ ] 有锚点，标注第几分钟，可判定
- [ ] 金句1句≤12字，说3次，说完停2秒
- [ ] 有≥1次低风险互动
- [ ] 有桥，制造了缺口
- [ ] 全块朗读一遍，无念不顺的句子
- [ ] 稿末写了"只许记住的一句话"

## 10. 套用本营的写作顺序（大纲→逐字稿）

1. 拿 [[100 大纲总表]]/[[110 D1上]] 的块，一块一块来，**倒着写**：先写锚点行，再写台词；
2. 每个"当场演示"按第3节三件套/五条/四步写，演示词按手机版写（复现走查已通过）；
3. 金句从 [[020 金句库]] 里选（J09"你说清楚，它就干得好"、J10"先跑起来，再改"都是 D1上 的）；
4. 互动按第5节低风险形式埋，救场话术备着；
5. 写完整块过一遍第9节自检清单。
