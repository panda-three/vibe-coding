#### 知识精讲
本节课先通过课堂提问回顾上午所学的占位符、自定义常量、转义字符知识点，随后核心讲解C语言中变量的概念、定义方式、赋值操作与实际使用场景，结合生活化案例和程序阅读习题帮助学生理解变量的“盒子”本质，掌握变量的基础运算与输出方法。

**上午知识点回顾：占位符**
* **四种基础占位符**：C语言中用于格式化输出的符号，分别对应不同数据类型。
   - 🚩重点：占位符与数据类型一一对应，输出时类型不匹配会得到错误结果。
   - 具体对应关系：`%d` 用于输出整型数据，`%f` 用于输出实型（浮点型）数据，`%c` 用于输出单个字符，`%s` 用于输出字符串。

**上午知识点回顾：自定义常量**
* **自定义常量定义规则**：通过预处理指令实现自定义常量的声明。
   - 🚩重点：必须以 `#` 开头，后续紧跟关键字 `define`，是C语言预处理阶段的核心语法。
   - *代码示例*：
```c
#define 常量名 常量值
```

**上午知识点回顾：转义字符**
* **三个核心转义字符**：用于实现特殊的输出控制效果。
   - 🚩重点：转义字符以反斜杠 `\` 开头，功能固定，不能随意自定义。
   - 具体功能：`\a` 实现响铃效果，`\n` 实现换行效果，`\t` 实现制表符（对齐）效果，`\0` 表示空字符。

**变量的核心定义**
* **变量的生活化解释**：变量是存储数据的“小盒子”，而非盒子内部存放的数据本身。
   - 🚩重点：变量是C语言所有题目的核心载体，几乎所有程序逻辑都需要通过变量实现。
   - *补充说明*：将计算机内存类比为大量排列整齐的小格子，每个小格子就是一个变量，用来存放运行过程中会发生变化的数据。

**变量的定义语法**
* **变量的组成要素**：定义变量必须包含两个核心部分，缺一不可。
   - 🚩重点：变量定义后必须加分号表示语句结束，同一行可以同时定义多个同类型变量。
   - *代码示例*：
```c
// 标准定义格式
数据类型 变量名;
// 示例：定义名为i的整型变量
int i;
```
   - *补充说明*：数据类型决定了“盒子”的大小和可以存放的数据类型，变量名是给这个盒子起的专属标识，用来区分不同的变量。

**变量的赋值操作**
* **赋值的含义**：将数据放入变量“盒子”中的操作，也可称为初始化或修改值。
   - 🚩重点：赋值操作会覆盖变量中原有的旧数据，新值会完全替换旧值。
   - *代码示例*：
```c
int i;
i = 10; // 向i变量中存入10
i = 20; // 覆盖原有数据，将i中的值修改为20
```
   - *补充说明*：可以将变量定义和赋值合并为一行代码，效果和分开写完全一致：`int i = 10;`。

**变量的运算与输出**
* **变量的基础运算**：变量可以直接参与加减乘除等数学运算，运算结果可以直接赋值给其他变量。
   - 🚩重点：变量参与运算时，使用的是当前盒子中存放的最新值，之前的旧值不会保留。
   - *代码示例*：
```c
int A = 10;
int B = 20;
int C = A + B; // C中存放的是A和B的和，结果为30
printf("%d", C); // 输出结果为30
```
   - *补充说明*：后续实际开发中，`printf` 函数的占位符后几乎都会搭配变量使用，而非直接写固定常量，这样才能让程序具备动态变化的能力。

**程序阅读习题：变量交换逻辑**
* **无临时变量的数值交换**：通过三次算术运算实现两个变量的值互换。
   - 🚩重点：每一次赋值后变量的值就会更新，后续运算使用的是更新后的新值，不能一直使用初始值计算。
   - *代码示例*：
```c
int A = 1;
int B = 2;
A = A + B; // A的值变为3
B = A - B; // B的值变为3-2=1
A = A - B; // A的值变为3-1=2
printf("%d,%d", A, B); // 最终输出结果为2,1
```

**变量命名规范实践**
* **见名知意的命名原则**：变量名要能直观体现它所存储的数据含义，提升代码可读性。
   - 🚩重点：不要使用无意义的单个字母作为业务变量名，尽量使用有实际语义的英文单词命名。
   - *代码示例*：
```c
int money = 100; // 定义表示微信余额的变量，初始值为100
money = money + 2; // 收到2元红包，余额更新为102
printf("%d", money); // 输出最终余额102
```

#### 🚩 考点重点
- [00:07:02](https://getnotes.seek:422) **变量的核心地位**：变量是C语言所有题目的核心载体，几乎所有程序逻辑都需要通过变量实现，是期末考试的必考点。
- [00:35:32](https://getnotes.seek:2132) **变量运算易错点**：变量被赋值后值会立刻更新，后续运算必须使用最新值，不能一直沿用初始值计算，这是程序阅读题的高频易错点。
- [00:36:12](https://getnotes.seek:2172) **多占位符输出规则**：`printf`中多个占位符会从左到右依次被后续变量替换，字符串中的普通字符（如逗号）会原样输出，考试中经常考察输出结果的格式细节。

#### 💡 核心概念
- **变量**：用来存储可变数据的“小盒子”，指的是内存中的存储单元本身，而非盒子内部存放的数据。
- **变量定义语法**：`数据类型 变量名;`，数据类型决定变量的存储大小和可存放的数据类型，变量名是变量的唯一标识。
- **赋值操作**：通过`变量名 = 新值;`的格式更新变量中的数据，新值会完全覆盖变量中原有的旧数据。
