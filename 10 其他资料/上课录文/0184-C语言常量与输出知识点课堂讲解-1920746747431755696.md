#### 知识精讲
本节课先通过课堂提问回顾上节课的整型常量、字符常量、转义字符等核心知识点，随后重点讲解实型常量的特殊写法、printf输出语句的占位符机制，补充自定义常量与常用转义字符的功能，帮助学生掌握C语言基础常量的输出方法。

**上节课知识点回顾**
* **整型常量的三种进制形式**：整型常量分为八进制、十进制、十六进制三类，八进制以数字0开头，十进制无前缀直接书写，十六进制以0x开头，使用A-F表示10-15的数值。
   - 🚩重点：十六进制的前缀容易被误写为0S，考试中会作为易错选项考察，需牢记正确前缀是0x。
* **字符常量的定义与存储**：字符常量是用单引号包裹的单个字母、数字或英文符号，在内存中以ASCII码的形式存储。
   - 🚩重点：三个核心ASCII码数值必须牢记：字符'0'对应48、大写'A'对应65、小写'a'对应97，是后续字符运算的基础考点。
* **转义字符的规则**：转义字符以反斜杠`\`开头，分为两类：一类是转义特殊符号（如`\\`输出单个反斜杠、`\'`输出单引号）；另一类是`\ddd`（八进制形式）、`\xhh`（十六进制形式），需通过按权展开转换为十进制后匹配对应字符。
   - 🚩重点：转义字符的进制转换计算是期末常考题型，必须熟练掌握按权展开的转换方法。

**实型常量的特殊写法**
* **小数点前后零的省略规则**：C语言中允许省略实型常量小数点前后的0，例如`.96`等价于`0.96`，`15.`等价于`15.0`，这是合法的实型常量写法。
   - 🚩重点：判断常量类型的核心依据是“是否包含小数点”，只要带有小数点就属于实型常量，哪怕数值本身是整数。
* **科学计数法的C语言规范**：数学中的科学计数法在C语言中必须用字母`e`表示“乘以10的幂次”，例如数学写法`123×10^5`在C语言中需写为`123e5`，否则属于非法写法。
   - 🚩重点：选择题中经常出现不带`e`的数学科学计数法作为干扰项，需快速识别其不属于合法C语言实型常量。

**printf输出语句的参数机制**
* **printf的双参数结构**：printf是C语言的标准输出函数，括号内可包含两类参数：第一个参数是“输出内容的最终样式”，为必填项；第二个及后续参数是“待填补的具体内容”，为选填项，当输出纯字符串时可省略。
   - 🚩重点：参数之间必须用英文逗号分隔，参数的数量要和占位符的数量一一对应，数量不匹配会导致程序运行异常。
* **占位符的定义与作用**：占位符以`%`开头，是预先占用输出位置的特殊标记，程序运行时会用后续的具体数值替换对应位置的占位符。
   - 常用占位符对照表：
     | 占位符 | 对应数据类型 | 英文全称来源 |
     |--------|--------------|--------------|
     | `%d`   | 整型         | decimal      |
     | `%f`   | 实型         | float        |
     | `%c`   | 字符型       | character    |
     | `%s`   | 字符串型     | string       |
   - 🚩重点：汉字属于多字节字符，不能用`%c`作为占位符，必须使用`%s`字符串占位符，这是高频易错考点。
* **多占位符的组合使用**：同一个printf语句的第一个参数中可以同时写入多个不同类型的占位符，后续参数按从左到右的顺序依次填补对应位置，大幅简化多行输出的代码量。
   - *代码示例*：
   ```c
   printf("姓名：%s 性别：%s 年龄：%d", "小明", "男", 15);
   ```

**自定义常量的定义**
* **`#define`预处理指令**：通过`#define 常量名 数值`的格式可以自定义符号常量，程序中所有出现该常量名的位置都会被自动替换为对应的数值。
   - *代码示例*：
   ```c
   #define N 10
   ```
   - 🚩重点：`#define`是预处理指令，末尾不能添加分号，这是初学者最容易犯的语法错误。

**常用转义字符功能详解**
* **核心必记转义字符**：要求重点掌握3个高频使用的转义字符：`\n`（换行）、`\t`（制表符）、`\0`（空字符），其余转义字符做了解即可。
* **制表符`\t`的对齐机制**：`\t`的作用等价于按下键盘的Tab键，会自动将当前输出位置跳到下一个8的整数倍列数，核心作用是实现多行输出内容的自动对齐，让打印结果更规整。
   - 🚩重点：`\t`不是固定空8个空格，而是根据当前光标所在列数动态调整空格数量，考试中会考察制表符的输出结果计算。

#### 💡 核心概念
- **占位符**：以`%`开头的特殊标记，预先占用输出位置，程序运行时用后续对应数值替换。
- **自定义常量**：通过`#define`指令定义的符号常量，程序中所有对应名称都会被替换为指定数值。
- **实型常量零省略规则**：小数点前后的0可以省略，`.96`等价于`0.96`，`15.`等价于`15.0`。
- **核心公式/代码**：
  ```c
  // 多占位符输出示例
  printf("姓名：%s 性别：%s 年龄：%d", "小明", "男", 15);
  // 自定义常量定义
  #define N 10
  ```
