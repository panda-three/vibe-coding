# 块八 ｜ 2:08–2:28 ｜ 回到定义：Skill 是什么（炒菜类比·结构映射·提示词≠Skill）

**锚点（自检式·不点名）：【第25分钟】每人能说出"Skill＝技能：流程＋配方＋工具＋材料，打包成一个文件夹"；台下信号：小声"哦——"或有人点头。**

【2:08–2:10 钩子＋结论】
**来，先别管英文。Skill 是什么？**（停1秒，自答）
**Skill＝技能。就是你"会做一件事"的本事。** 【上屏】`中文就两个字：技能。`
**但今天下午，我们给它一个更值钱的解释——**（停1秒）
`一个技能，不是一句话，是四样东西：流程、配方、工具、材料。` 【上屏四格】

【2:10–2:15 拆解·炒菜类比（核心教学道具）】
**比如说，你是一个厨师。**（停1秒）`你的技能是什么？炒菜。`
**技能1：炒菜。** 【上屏卡通厨师＋四格】
**要炒好一盘菜，你得有四样：**
`第一，流程——炒菜顺序。先备菜、再热锅、再下菜、再调味，一步不能乱。`
`第二，配方——油温多高、盐放多少。差一点，味道就不同。`
`第三，工具——煤气灶、炒锅。没有锅，手艺白搭。`
`第四，材料——你的独家食材。`
（停1秒）**流程、配方、工具、材料。少一样，这盘菜都炒不成。**（重复一遍）

【2:15–2:20 结构映射·上屏】
**关键来了：一个 Skill（技能），就是把这四样装进一个文件夹。** 【上屏结构图】
`流程 → 一个叫 SKILL.md 的文件（怎么做的主流程说明）`
`配方 → 一个叫 references 的文件夹（参数、标准、参考文档）`
`工具 → 一个叫 scripts 的文件夹（能直接执行的脚本）`
`材料 → 一个叫 assets 的文件夹（素材：图片、logo）`
（停2秒）**一句话记住：Skill（技能）文件夹 ＝ SKILL.md ＋ references ＋ scripts ＋ assets。**（重复）
`别被英文吓到——它就是炒菜那四样，换了个名字放进文件夹。`
（备：有人问"这跟我们有什么关系"）`你上午那 4 行模板，就是迷你版的 SKILL.md——你已经会了，只是没装进文件夹。`

【2:20–2:24 点破·提示词≠Skill（认知转折点·配对比）】
**那我们平时不是老跟 AI 说话吗？那不就是提示词吗？——注意，不一样。** 【上屏大字】
**提示词 ≠ Skill。**（停2秒）`提示词，是每次现说一遍；Skill，是把方法存下来、工程化。`
**Skill 在工程上更有优势——比普通提示词，有用得多。**（"要多很多"，重复一遍）
`为什么？给你一个最直观的对比：`
`没 Skill 的时候，你想让 AI 做一张图——拷贝提示词 → 打开软件 → 粘贴 → 生成 → 下载保存。五步。`
`有 Skill 的时候，一句话："帮我做一张周六饮料免费的实体海报。" 它自己干。`（停2秒）
`五步变一句——这就是"工程上更有优势"。`

【2:24–2:26 跟做·60 秒微跟做】
**来，60 秒，就写一个你自己的"技能"。** 【大屏计时】
`打开便签，写四行：`
`第一行，流程——你做这件事，先干什么后干什么。`
`第二行，配方——有什么讲究？比如"油温""多少字""什么格式"。`
`第三行，工具——要用到啥？手机？电脑？某个软件？`
`第四行，材料——要准备啥？素材？资料？`（停60秒；走动）
（提示）`写不出来？就写你最熟的那件：改通知、做课件、收拾桌子——都行。`

【2:26–2:28 回收＋锚点＋桥】

`恭喜，你已经写出一个"技能"了。它就是 Skill 的种子。`

# 块九 ｜ 2:28–2:48 ｜ 拆开看：Skill 长什么样（元信息＋指令·按需加载三层）

**锚点（可判定）：【第46分钟】每人能说出"Skill 为什么省——AI 先只看元信息，用到才加载"；台下信号：有人点头／小声"哦——"。**

【2:28–2:30 钩子＋拆真 Skill】
**来，光说没用。我拆一个真的给你们看。** 【切大屏：秋芝餐厅 SKILL.md】
`这个 Skill，是别人真在做生意用的——一家叫"秋芝餐厅"的店。`
**一个 SKILL.md，就两部分：** 【上屏标注】
`第一部分，元信息——就是两行：名字（name）＋一句话说明（description）。`
`它管什么？——"为秋芝餐厅生成符合品牌调性的物料设计创意"。`
**第二部分，指令——具体怎么干活。**（停1秒）`比如：品牌核心元素（品牌名、风格、IP形象、配色、Slogan）、你的任务（做海报/易拉宝/工服/包装盒时怎么输出）、输出格式（先给创意主题，再给细节建议）。`
（停2秒）**元信息管"认不认识它"，指令管"它怎么干"。就这两件事。**

【2:30–2:36 拆解·按需加载三层结构（核心机制·上屏图）】
**那它凭什么省？关键在这四个字：按需加载。** 【上屏大字】
`AI 看到"做一张海报"，它不是把整个 Skill 全背下来，它分三层看：`
**第一层，元信息——始终加载。** `就 name＋description 两行，极小。AI 先扫一眼：这事归不归它管？`
**第二层，指令层——按需加载。** `归它管了，它才去读 SKILL.md 里的完整规则。`
**第三层，资源层——按需加载。** `要具体规格，去读 references；要执行，去跑 scripts；要用素材，去拿 assets。`
（停2秒）**用一句话记：AI 先看元信息，用到才加载。**（重复）
**三个好处，就三个：** 【上屏】
`第一，省 token——不用的内容，根本不加载。`
`第二，不干扰——它不会把别的 Skill 的东西串进来。`
`第三，更准——用到什么，才读什么。`
（反面案例）`反过来，你把这些要求全塞进一句提示词——一次两次行，十次就乱：token 浪费，还互相干扰。`

【2:36–2:41 演示·讲师现场拆一个＋一句话出图（现象→命名→验证）】
**来，大家看大屏，我现场拆我自己手机里的。** 【切豆包/Skill 列表，坐标口令：看左边那一列】
`这个、这个、这个——每个都是一个文件夹。我点开一个。`【点开，指元信息】`看，第一行名字，第二行一句话说明。下面才是干活的规则。`
**再看它干活——我现在只说一句话：**（打字）`"帮我做一张周六饮料免费的实体海报。"`（停3-5秒）
（演示等待期不冷场）`哎，它在想。它先去认元信息——归我管；再去读规格——实体海报的尺寸要求；然后出创意，调用工具生成。`
**看，出来了。**（停2秒）`五步变一句——就是这三层按需加载在干活。`
（备：生成慢/失败）`没事啊，这不就是真实情况嘛，等一下就好。这一步看的是"它怎么想"，不是那张图。`（若彻底失败）`看这个列表结构就行——元信息管认，指令管干，资源管细节。`

【2:41–2:45 跟做·60 秒微跟做（元信息练习）】
**来，60 秒，给你刚才那个"技能"补两行。** 【大屏计时】
`第一行，名字（name）——给它起个名，三个字以内，比如"通知助手"。`
`第二行，一句话说明（description）——它管什么。`（停60秒；走动）
（提示）`不会起名？就叫"我的XXX"，先跑起来。`

【2:45–2:48 回收＋锚点＋桥】
**低头看手机——补了两行的，抬头看我。**（停3秒）
`现在你手里这个，已经有了"元信息＋流程"——它就是 Skill 的种子，只是还没装进文件夹。`
**一个完整的 Skill 长什么样，看个真的。下一块，我的知识库。**

**只许记住这一句：AI 先看元信息，用到才加载——省 token、不干扰、更准。**

# 块十 ｜ 2:48–3:03 ｜ 案例 C07：把"重复的事"做成工具（知识库＋Skill）

【2:51–2:57 讲案例＋演示（C07：现象→命名→验证）】

`第一件：飞书里的课程文档，怎么转进来？`
`第二件：这么多文档，健康度怎么样？有没有断链、废稿？`
`第三件：新东西来了，放哪个文件夹归档？`
**这三件，是不是"重复的事"？**（停1秒）`是。所以——打包。`
**我做了一个 Skill：导入、体检、归档。** 【上屏三词】`一个 Skill，管三件重复的事。`
**来，看它干活，快速走一遍。** 【切回操作，动作快过】
`我给它一个链接——导入。`（动作）`它自己抓全文、存成文件。`
`我说"体检一下"——体检。`（动作）`它自己扫一遍：哪篇断链、哪篇空。`
`我说"归档"——归档。`（动作）`它自己分类放好。`
**停一下，看两秒。**（停2秒）`它干的，全是重复里最烦的部分——下载、整理、命名、检查。`
（小故事·C12）`说个真的。我最烦的是课程转录——以前一篇 2-3 小时，人盯人。打包成 Skill 之后，几分钟。`（停1秒）`两三个小时变几分钟——这就是"重复的事，值得做成工具"。**

【2:57–3:00 点破·G05 配案例（认知转折点）】

**你们也一样。** `老师最重复的是什么？改通知、整理材料、回家长消息——哪一件值得打包，你自己最知道。`
（若有人问"我不会写 Skill 怎么办"）`不会写，不怕——你只要能把"重复的事"说清楚，剩下的，让 AI 帮你打包。这就是下一块的活。`

# 块十一 ｜ 3:03–3:15 ｜ 怎么造一个 Skill（写清楚·或让 AI 帮你造）

**锚点（可判定）：【第3:13分钟】每人手机里有一条"让豆包把自己技能写成规则"的消息（完成或半成品）。**

【3:03–3:06 结论＋Creator 原理】
**想自己造一个？先给结论：** 【上屏】
`第一，你不是手写代码——你是写清楚流程。`
`第二，连流程都能让 AI 帮你写——用一个叫"Skill 创建器"的东西。`
`什么叫创建器？它自己也是个 Skill。它的活儿，就是帮你造 Skill。`
**它怎么问你？就四个字：大白话＋选择题。** 【上屏】（停1秒）
`它不问你"您的需求文档呢"——它问你人话：`
**"你想做一个什么样的 Skill？简单来说，你希望只要输入什么，AI 就输出什么？"**（停1秒）
`然后一道一道选择题：要解决哪类事？用户会提供什么素材？有没有现成的品牌资料？——你选，它记。`
**收集完，它自动把整套文件给你生成出来：SKILL.md、references、assets、scripts。**（停1秒）
`你全程没写代码，就回答了问题。`

【3:06–3:10 对齐训院四步（把"拷问需求"坐实）】
**这其实就是我们说的"训院四步"——造 Skill 前，四步，一步不能少。** 【上屏：拷问需求→demo→开发→测试】
`第一步，拷问需求。` **注意，拷问不是严刑逼供——就是创建器那套：大白话＋选择题，把"你到底要解决什么"问清楚。**
（例子）`我当时问自己：最烦的是哪件？——把课程文档转成 Markdown，太慢。就这一件。`
**判断标准一句话：这件事，是不是重复发生？** `只发生一次的，别做。`
`第二步，demo——先做个最小的、能用的。`
`第三步，开发——把各种情况接住。`
`第四步，测试——真的跑一遍，坏了就修。`
（停2秒）**顺序记牢：先想清楚，再动手。** `创建器帮你做的，就是把第一步"拷问需求"自动化了。`

【3:10–3:13 演示＋跟做·学员动手（讲师先演示，再跟做 90 秒）】
**来，我先演示一遍，你们只看。** 【切豆包，打字】
`我把我那个"炒菜技能"发给豆包：`（打字）`"帮我把这个整理成一段操作说明：流程、配方、工具、材料。"`（停3秒）`看，它给我一段规规矩矩的规则——这就是 SKILL.md 的雏形。`
**好了，轮到你们。90 秒。** 【大屏计时】
`打开豆包，把你便签里那四行（流程/配方/工具/材料）发过去，加一句：`**"帮我把这个整理成一段操作说明。"**
`基础版：照我说的发一遍。进阶版：再补一句"以后我要做这件事，就按这个来"。`（停90秒；走动，个别指导）
（时间到）**没发完的没关系，先把四行补全——骨架进脑子，比发出去重要。**
（备：豆包答得乱）`没关系，你只要看到它"按你给的流程，整理成规则"这个动作——这就是造 Skill 的本体。`

【3:13–3:15 回收＋锚点＋桥】
**低头看手机——有一段"规则"出来的，抬头看我。**（停3秒）
`恭喜。名字、一句话说明、四行流程——你现在手机里，已经有一个 Skill 的种子了。`
**但还有一条更省的路：有些 Skill，根本不用造。下一块，收口。**

**只许记住这一句：你不是不会写 Skill，你只是没把"重复的事"说清楚。**

# 块十二 ｜ 3:15–3:30 ｜ 收口：现成 Skill＋什么值得做成 Skill＋抽查提问＋悬念

【3:15–3:18 现成 Skill 资源（拿来即用）】
**来，最后一点干货：有些 Skill，不用造，拿来就能用。** 【上屏清单】
`网上已经有人把常用的打包好了——通用的就这些：`
`做 PPT、文档处理、表格处理、PDF 处理、图片生成、动画生成、技能创建、前端设计、多步骤规划。`
**这些，往你的工具里一放，就是现成的"员工"。**（停1秒）
`它们背后有个机制，叫"渐进式披露"——想听的就记一句：AI 不把东西一次全倒给你，它一层一层给，用到哪层给哪层。`
（停1秒）`这不就是我们刚讲的按需加载嘛。一个意思。`

【3:18–3:21 什么值得做成 Skill（金句）】
**那到底什么事，值得做成 Skill？就两个条件。** 【上屏】
`第一，结果要求明确——你知道要的是啥。`
`第二，你有经验和方法——这活你熟。`
**满足这两条，又是重复发生的——都该做成 Skill。**（停1秒）
`给你看三种人：`
`打工人——周报，每周写，做个"周报 Skill"，数据给它，报告它出。`
`创作者——文章总要配图，做个"图文编辑 Skill"，丢文章，配图它给。`
`法务——天天审合同，做个"审合同 Skill"，合同丢进去，风险点它标。`
（停1秒）**那就做一个。都该用用。**

【3:21–3:26 抽查提问·三问（替代亮结果）】
**来，三问。答不出的，同桌帮一把，我不点名。**
**第一问：Skill 是什么？**（停3秒，自答兜底）`技能——流程＋配方＋工具＋材料，打包成一个文件夹。`
**第二问：Skill 为什么比普通提示词省？**（停3秒，自答兜底）`因为它按需加载——AI 先看元信息，用到才加载，不用的不费 token。`
**第三问：想造一个 Skill，第一步是什么？**（停3秒，自答兜底）`拷问需求——用大白话＋选择题把"到底要解决什么"问清楚，先想清楚再动手。`
（每问后）`觉得答得上的，点头。没答上的，看同桌，让他给你说一遍。`（停5秒，走动）

【3:26–3:28 金句收口】
**今天下午，两句话带走：**
`第一句：好作品，是复刻出来的。`
`第二句：你会的那些事，都该做成 Skill——都该用用。`（均上屏，重复一遍）
`记住：你刚才是甲方。你给它骨架，它给你成品；你给它重复的事，它给你工具。`
